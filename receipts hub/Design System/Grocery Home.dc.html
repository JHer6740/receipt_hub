What I decided

Organic's cream ground already reads as receipt paper, so I kept it and re-assigned the accents to the brief's semantics rather than inventing a second palette.

Sage — primary action, confirmed, checked
Terracotta — the brief's amber: uncertainty, needs review
Tomato — added token, deletion only
Blue-grey — added token, secondary text

Type

Caprasimo is Organic's only display voice, but it has no tabular figures — so it carries screen titles and hero amounts only. Every price, quantity and total in a list is Figtree with tabular-nums. The receipt photo itself is IBM Plex Mono standing in for thermal print.

The receipt strip

A torn-bottom paper card: date in mono small caps, merchant, a dashed rule, item count, total, status marker. It appears on Home, in duplicate warnings, and can carry search results. Toggle Strip edge in Tweaks to compare torn against a clean card.

Try this

  • Tap Scan, shoot, and watch the named stages — no fake percentage.
  • In Review, add a line for Chilli loose · 0.99 and the balance panel turns from amber to sage.
  • Delete every product line — Save stays enabled.
  • Flip dark theme; all colour comes from semantic tokens.
